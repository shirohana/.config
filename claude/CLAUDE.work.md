# Work laptop additions

Rules the work laptop appends to `CLAUDE.md`; the home laptop never loads this file.
A rule lives here only while it is wrong for home. Reason: a rule inside the shared
file is read on both machines even when marked "work only".

# Execution

**PIN THE UPSTREAM, FINISH THE UNIT** – Depending on something under active change? Pin a version, finish the unit against it, then re-sync and diff — never chase upstream mid-unit. Before a finding goes outward, re-check it against your pinned build; drift is co-work, so report the drift, not a culprit.
